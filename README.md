# YesAI

**This world is better with AI.**

These are public domain images that anyone can use, modify, or place in VRChat worlds
to show support for generative AI.

Join the VRChat group: **YESAI.5180**

## Usage

- Download any image from the `images/` folder.
- Place the poster front-and-center in your VRChat world.
- Edit the assets freely. Be creative, but please be respectful to your players.
